Install

  1. Keep the texel-*.zip you just downloaded zipped. Blender wants the zip, not the folder inside it.
  2. In Blender: Edit → Preferences → Get Extensions, then the small arrow at the top right → Install from Disk…
  3. Pick the zip. Texel enables itself.

The older route works too, if that is the one you know: Edit → Preferences → Add-ons → the arrow at the top right → Install from Disk… The zip ships as both a Blender extension and a classic add-on, and both routes were run against 4.2.23, 4.5.9 and 5.2.1 before this page was written. Nothing else to install — no numpy, no compiler, no account, no internet.

Did it work?

Open an Image Editor or a 3D Viewport, press N for the sidebar, and look for a Texel tab down the right-hand edge. That tab is the whole add-on.

No tab? Nine times out of ten the sidebar is shut — press N with the mouse inside the editor, not over a menu. If it still is not there, open Preferences → Add-ons, search Texel, and read the error under the entry. Send me that error and I will tell you what it means.

Installed Blender from the Microsoft Store? That build is tested and works. Windows redirects its add-on folder, so if you ever go looking for the files by hand they are under %LOCALAPPDATA%\Packages\BlenderFoundation.Blender_*\LocalCache\Roaming\ and not the %APPDATA%\Blender Foundation\ path most guides give.

Your first five minutes

In the 3D viewport sidebar: Texel → Setup → Add 1m Cube. One button makes the cube, an image, a material and a UV map, and sets the texture filter to Closest so your texels stay square. Pick a colour, pick Pencil, and draw straight onto the cube.

Then the thing you probably came for: select some objects, Texel Density → Detect Density to see the pixels-per-unit you actually have, set a target (24–48 px/unit suits most games), and Apply Density to put every face on the same texel size. Snap UVs to Pixels afterwards removes half-texel seams.

Open texel/START-HERE.html from inside the zip for the guided version, with the animation and tiling walkthroughs.

What you need

Blender 4.2 or newer. Measured against 4.2.23, 4.5.9, 5.2.1 and the Microsoft Store build — all four pass. Built and tested on Windows: it is platform-independent Python, but I have not tested macOS or Linux and will not claim it. GIF export needs ffmpeg on PATH; sheet and JSON export need nothing.
