1Install it

  1. Keep texel-0.1.0.zip zipped. Blender wants the zip, not the folder inside it.
  2. Open Blender. Edit → Preferences → Add-ons.
  3. Top-right ▾ → Install from Disk… and pick the zip.
    On Blender 4.2–4.4 the button is Install… in the same place.
  4. It enables itself. If it does not, tick the checkbox next to Texel.
How you know it worked
Open the Image Editor or a 3D Viewport, press N to open the sidebar, and look for a Texel tab down the right-hand edge. That tab is the whole add-on.
If the tab is not there
Nine times out of ten the sidebar is closed — press N inside the editor, not over a menu. If it still is not there, the add-on did not enable: go back to Preferences, search Texel, and read the error under the entry. Send me that error and I will tell you what it means.

2Your first five minutes

Do this once and the rest of the tool explains itself.

Paint a texture on a model

  1. In the 3D viewport sidebar, Texel → Setup → Add 1m Cube. That one button makes the cube, an image, a material and a UV map, and sets the texture filter to Closest so your texels stay square instead of being blurred.
    Bringing your own model? Unwrap it, then use Pick Texture to point Texel at its image.
  2. Pick a colour and a tool (Pencil is fine) and draw on the cube in the viewport. Strokes land where you point, resolved through the UVs.
  3. Open an Image Editor beside it to see the flat canvas update as you paint.

Fix the thing you came here for

  1. Select a few objects. Texel Density → Detect Density reports the pixels-per-unit across them — average, range, spread.
  2. Set a target (24–48 px/unit suits most games) and hit Apply Density. Every face is rescaled to the same texel size.
  3. Snap UVs to Pixels afterwards kills half-texel seams.

Animate a sprite

  1. In the Image Editor sidebar: Sprite → Add Frame, four times.
  2. Add Track with Behind ticked for a background. Now one frame holds a character and its backdrop, on separate cels.
  3. Draw on each cel in the grid. Turn on onion skin to see the neighbouring frames of the track you are editing.
  4. Play binds it to Blender's own timeline — spacebar plays it.
  5. Export Sheet + JSON, or GIF if you have ffmpeg.

3The things that trip people up

What you seeWhat it is
The texture looks blurry / smudged The image texture is interpolating. Add 1m Cube sets Closest for you; if you made the material yourself, set the Image Texture node's interpolation to Closest.
Pixels are bigger on some faces than others That is texel density drift, and it is the whole reason this tool exists. Apply Density on every object with the same target.
“Palette full (255 colours)” The canvas is indexed and holds 255 colours plus transparent. It refuses rather than silently quantising your art. Reduce colours, or start a new canvas.
Painting does nothing in the viewport The object needs UVs and an image texture. Run Add 1m Cube, or assign your own image to the material.
Export GIF is greyed out or errors GIF needs ffmpeg on your PATH. Sheet and JSON export do not — use those instead if you would rather not install it.
How much does one undo take back? Undo is per action, through Blender's own stack — one Ctrl+Z takes back a whole fill — which is one action, so that is right. Painting is modal, so one drag is one undo step.
Where are the keyboard shortcuts? There are: B pencil, E eraser, L line, U rect, C ellipse, F fill, I picker, M mirror, D paint in the Image Editor, and D to paint in the 3D viewport. Rebind any of them in Preferences → Keymap, search “texel”.

On the licence, plainly
Every Blender add-on that uses bpy must be GPL — that is Blender's licence, not a choice I made. It means the source is in the zip and you may modify and pass it on. It puts no restriction on the art you make with it. Sell your sprites, your packs, your game. No royalty, no attribution.
